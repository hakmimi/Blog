# Applied ML Notebook

A multi-series, code-first blog about applied machine learning, built with Astro. Each article has a creation date and keywords; keywords generate topic pages (`/topics/`), and each series lives under `/series/<series>/`.

Currently published:

- **Classification, Run for Real** (16 parts): the UCI Bank Marketing data (`bank-additional-full`), twelve classifiers and a no-model baseline compared under one written protocol, with runnable code and output generated by the experiments that the text cites.
- **AI Engineering, Day by Day**: two systems built one small step at a time.

## Build the site

Requirements: Node.js 22+.

```powershell
npm install
npm run build
python scripts\validate_site.py     # frontmatter, word counts, broken links, search index
```

`npm run dev` for authoring, `npm run preview` after a build. Output goes to `dist/`.

## Reproduce the classification series

Requirements: Python 3.13 (the recorded run), then, from this folder:

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.lock.txt          # exact versions of the recorded run; requirements.txt has ranges
cd series\classification\scripts
python download_data.py                  # UCI download, checksums, and the dataset's own documentation file
python protocol.py                       # writes protocol_manifest.json and feature_availability.csv
python run_all.py data metrics linear svm_folds leaderboard uncertainty policy objectives calibration dev_studies importance temporal stability
python run_all.py timing                 # alone: it measures speed and must not share the CPU
python summarise.py                      # small derived tables
python export_widgets.py                 # JSON for the two browser widgets
python make_figures.py                   # every figure, drawn from the artifacts only
cd ..\..\..
python scripts\build_articles.py         # render articles from templates; runs and re-prints every code snippet
python scripts\check_series.py           # consistency checks
npm run build
python scripts\build_print.py classification --title "Classification, Run for Real"   # printable edition
```

The full run takes several hours on a 12-thread laptop (CatBoost and the repeated-split study dominate). Steps write into `series/classification/artifacts/`, and each one can be re-run alone. Results do not change between runs on the same versions; timings do.

### Where things live

| Path | What it is |
|---|---|
| `series/classification/articles/NN-*.md` | The article **sources**. Tables and key numbers are tokens (`@@table:...@@`, `@@v:...@@`) filled from the artifacts. Python snippets are executed at render time and their printed output replaces the output block. |
| `src/content/articles/classification/` | Rendered articles (generated by `scripts/build_articles.py`; do not edit by hand). |
| `series/classification/scripts/protocol.py` | The evaluation protocol and data contract: splits, feature sets, price list. Every experiment imports it. |
| `series/classification/scripts/exp_*.py` | One experiment per chapter group (see `run_all.py`). |
| `series/classification/artifacts/` | Authoritative result tables: split manifest, every candidate evaluated, frozen predictions, uncertainty and policy tables. |
| `series/classification/figures/` | Figures, drawn by `make_figures.py` from the artifacts. |
| `public/js/` | The two browser widgets (threshold lab, prior-shift lab). |
| `docs/` | Technical change log and the completion report for the publication-quality revision. |

### The protocol in five lines

- One row is a **record**; the file has no client identifier.
- **Development** rows (80%, stratified random, seed 42) are used for every choice. The **comparison** rows (20%) are scored for frozen pipelines. Earlier drafts looked at them while exploring, so they are a teaching benchmark, not an untouched test set.
- A **chronological** split (first 80% of rows for development, last 20% as the future) answers the deployment question in part 16. Row position is a proxy for time; the file has no dates.
- **Price list:** a contact costs 1 and a subscription is worth 8, as illustrative assumptions. Contributions are retrospective policy simulations, not value caused by contacting.
- Ranking metrics use unclipped scores. Calibrators wrap the full preprocessing-plus-model pipeline.

## Add a new series

1. Add an entry to `src/data/series.ts`.
2. Put articles in `src/content/articles/<series>/NN-slug.md` with frontmatter: `title, description, series, order, date, keywords[], readingTime, figure`.
3. Put scripts, figures and artifacts in `series/<series>/{scripts,figures,artifacts}`. `npm run sync` copies them to `public/series/<series>/`.
